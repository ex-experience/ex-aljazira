# EX™ ALJAZIRA // Voxel Kingdom — V1

هذه نسخة Vibe-Code ديمو أصلية للمتصفح، من نوع voxel sandbox / survival-builder، مستوحاة من جغرافية المملكة العربية السعودية بدون نسخ Minecraft أو أصولها أو واجهتها أو علاماتها.

## ما يعمل الآن
- عالم Voxel مولد إجرائياً.
- Biomes سعودية: HIJAZ / NAJD / TUWAIQ / HARRAT / OASIS / RUB_AL_KHALI.
- منطقة مبنية مستوحاة من عمارة جدة التاريخية بأسلوب voxel أصلي.
- First-person movement + sprint + jump.
- كسر ووضع الكتل.
- 7 خامات أصلية.
- Day/Night cycle.
- بعثة تأسيس أولية.
- PWA manifest.
- Touch controls أولية للجوال.
- Seed ثابت V1: 2030.

## التشغيل
1. فك الضغط.
2. شغّل `START_LOCAL_WINDOWS.bat`.
3. افتح:
   `http://localhost:8080`

## التحكم
- WASD: حركة
- SHIFT: ركض
- SPACE: قفز
- Left click: كسر
- Right click: بناء
- 1-7: اختيار الكتلة
- P: إيقاف

## ملاحظة IP
هذا المشروع لا يستخدم كود Minecraft أو Textures أو UI أو أسماء مخلوقات أو عناصر أو خرائط أو ملفات تابعة لها.
الفكرة العامة "Voxel sandbox / building / survival" هي نقطة انطلاق نوعية، بينما الهوية، الجغرافيا، الأنظمة، الأسماء، العالم والأصول هنا أصلية.
